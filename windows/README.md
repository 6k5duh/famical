# Famical for Windows v2.0.4

[Windows x64 다운로드](../downloads/famical-windows-2.0.4-x64.zip)

1. NAS 소스를 v2.0.1으로 업데이트하고 Container Manager에서 다시 빌드합니다. 기존 데이터 볼륨과 관리자 설정 파일을 유지합니다.
2. 실행 중인 Windows 앱을 트레이 아이콘 우클릭 → 종료로 닫습니다.
3. 새 ZIP 전체를 별도 폴더에 압축 해제하고 `Famical.exe`를 실행합니다. Windows 10/11 x64와 .NET Framework 4.8이 필요합니다.
4. 기본 서버 `https://famical.ymsh.synology.me/`의 가족 계정으로 로그인합니다. 처음 로그인하고 동기화를 마친 뒤에는 인터넷이 끊겨도 저장된 일정과 달력을 사용할 수 있습니다.

v2.0.1은 WPF로 달력을 직접 그립니다. WebView2 설치 없이 실행하며, 서버에서는 JSON 데이터만 받아옵니다. 브라우저의 기존 웹앱도 같은 서버에서 사용할 수 있습니다.

## 오프라인 일정

일정 저장은 기기에 즉시 반영됩니다. 연결 중이면 저장 후 동기화하며, 실행 중에는 1분마다 다시 시도합니다. 창을 트레이로 숨긴 상태에서도 동기화를 시도합니다. 상태 줄에 미전송 개수와 마지막 동기화 시각을 표시합니다.

기기 재시작 후에도 미전송 변경은 보관합니다. 같은 일정을 다른 기기에서 수정·삭제했다면 설정에 두 내용을 표시하며 **내 변경 적용** 또는 **서버 일정 사용**을 선택합니다. 서버에서 삭제된 일정에 내 변경을 적용하면 새 일정으로 등록합니다. 유효하지 않은 변경이나 권한 오류도 설정에서 확인하고 취소할 수 있습니다.

서버 로그인 유효 기간이 끝나도 기기 일정은 열 수 있습니다. 설정에서 **같은 계정으로 재로그인**하면 동기화를 재개합니다. 미전송 일정이 있으면 동기화·충돌 확인 후 로그아웃합니다.

일정과 로그인 세션은 `%LOCALAPPDATA%\Famical\native-*.bin`에 Windows 사용자 계정으로 암호화하여 저장합니다. 앱 업데이트 시 이 폴더를 유지하세요. 다른 서버는 트레이에서 종료한 뒤 `window.xml`의 `server`에 HTTPS 주소를 설정할 수 있으며, 서버별 저장 파일을 사용합니다.

일정 색상은 배경색과 구분되는 16가지이며 선택창에 색상 견본을 표시합니다.

## 달력 사용

날짜 칸의 빈 공간을 **더블클릭**하면 해당 날짜의 간편 입력창이 열리고 바로 입력할 수 있습니다. 이전 달·다음 달의 날짜 칸에서도 사용할 수 있습니다. 날짜 숫자는 일정이 있으면 목록을, 없으면 간편 입력창을 엽니다. **+ 일정**은 오늘 날짜의 간편 입력창을 엽니다. 한 줄에 하나씩 입력하고 **저장**을 누르세요. `14:00 생산 워크숍`처럼 시간을 앞에 붙일 수 있습니다. 새 일정 입력 중 **Esc**를 누르면 저장하지 않고 창을 닫습니다. **상세**를 펼친 상태에서도 취소할 수 있습니다. Windows 새 일정의 기본값은 **회사 · 나에게만 보이기**입니다.

**상세**에서 시작일·종료일, 양력·음력, 매년 반복·윤달, 가족·회사, 공개 범위, 색상, 메모를 설정합니다. 숫자 8자리 날짜도 입력할 수 있습니다. 기존 일정을 누르면 상세 내용을 편집합니다. 날짜의 **+N개**에서 숨겨진 일정을 확인합니다.

회사 연속 일정은 토·일을 건너뛰고 평일 경과 일수·총일수를 표시합니다. 첫 주·마지막 주에는 이전 달·다음 달 날짜를 55% 농도로 표시합니다. 음력은 1900~2050년, 공휴일 데이터는 1900~2099년 범위를 포함하며 2027년 회사 휴무를 반영합니다. 공휴일 제도가 바뀌면 앱 데이터도 업데이트해야 합니다.

설정에서 작성자·일정 구분 필터와 계정에 저장할 교대조를 선택합니다. 가족 계정 생성과 비밀번호 변경은 같은 서버의 웹앱에서 이용할 수 있습니다.

## 창과 트레이

FAMICAL을 드래그해 이동하고 테두리나 모서리로 크기를 바꿉니다. 투명도는 0~60%로 조절합니다. 창 위치·크기·최대화 상태·투명도를 자동 저장하고 다음 실행 시 복원합니다. 트레이로 숨기거나 종료할 때도 저장합니다. 업데이트 후 원하는 위치·크기로 한 번 조절하세요.

- **−**, **×**, **Alt+F4**를 누르면 트레이로 숨깁니다.
- 트레이 아이콘 클릭 또는 실행 파일 재실행으로 달력을 엽니다.
- 트레이 아이콘 우클릭 → **종료**로 완전히 닫습니다.
- 바로 가기 대상에 `"C:\Famical\Famical.exe" --tray`처럼 `--tray`를 붙이면 처음부터 숨겨 실행합니다.
- 달력과 편집창은 작업표시줄·Alt+Tab 전환 목록에서 제외됩니다.

## 소스에서 빌드

.NET 8 SDK로 저장소 루트에서 `dotnet build windows/Famical.csproj -c Release`를 실행합니다. 배포 ZIP은 `windows/bin/Release/net48`의 EXE, EXE.config와 THIRD_PARTY_NOTICES.txt를 포함합니다. 달력 데이터는 EXE 안에 압축되어 있습니다. 재생성은 Python 의존성을 설치한 뒤 `python native/build_calendar.py`로 실행합니다.
