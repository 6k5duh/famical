# Calendar sync and account shift settings

Android **v1.2.0** / NAS web app **v1.3.0**

## 먼저 업데이트

1. NAS의 기존 프로젝트에 이 저장소의 최신 소스를 적용합니다. 새 `calendar_sync.py`도 함께 있어야 합니다.
2. Container Manager에서 기존 프로젝트의 이미지를 다시 빌드하고 컨테이너를 재생성합니다. Compose를 이용한다면 프로젝트 소스 폴더에서 아래 두 명령을 차례로 실행합니다.

```sh
docker compose build --no-cache calendar
docker compose up -d --force-recreate calendar
```

기존 데이터 볼륨·데이터베이스·`initial-admin.env`는 유지하세요. 삭제하거나 새 관리자 비밀번호를 만들 필요가 없습니다. 기존 DB에는 설정·연동 테이블이 자동으로 추가됩니다. 업데이트 전에는 기존 데이터 백업을 보관하세요.

3. 웹 화면 하단의 **Famical v1.3.0**을 확인합니다. 이전 버전이면 브라우저를 새로고침하고 실행 중인 이미지가 다시 빌드되었는지 확인합니다.
4. [Android v1.2.0 APK](https://github.com/6k5duh/famical/raw/refs/heads/main/downloads/famical-android-1.2.0-debug.apk)를 기존 앱 위에 업데이트 설치합니다. 이전 APK와 같은 디버그 서명을 사용합니다.

## 교대조 저장

로그인한 달력의 **내 교대조**에서 `A조`, `B조`, **해당 없음 (주간)**을 선택합니다. 선택 즉시 NAS의 해당 계정에 저장합니다.

- 해당 없음: 평일을 주간 색상으로 표시하고 주간으로 안내합니다.
- 교대 표시 OFF: 평일 주간·야간 음영을 없앱니다.
- 주말 색상은 기존과 같습니다.
- 로그아웃·재로그인·다른 기기에서도 같은 계정의 설정을 읽습니다.
- 기존 기기에만 저장했던 교대조는 자동으로 계정에 옮기지 않습니다. 업데이트 후 원하는 값을 한 번 선택해 주세요.
- Android 위젯은 다음 갱신 때 반영합니다. iPhone Scriptable 사용자는 [새 파일](../downloads/FamicalCalendar.scriptable)을 같은 이름으로 교체하세요. 개인 일정 표시 여부는 위젯별 기기 설정입니다.

## 삼성·휴대전화 캘린더 연결

1. 삼성 캘린더에서 원하는 계정의 일정이 실제로 보이고 동기화되는지 확인합니다.
2. 가족 달력 Android 앱에서 NAS에 접속하고 본인의 가족 계정으로 로그인합니다.
3. 상단 **서버** → **삼성·휴대전화 캘린더 연동**을 누릅니다.
4. Android의 캘린더 읽기·쓰기 권한을 허용합니다.
5. 읽기·쓰기가 가능한 캘린더 하나를 선택합니다. 이름 옆의 계정 유형으로 삼성·Google·기기 캘린더를 구분할 수 있습니다. 동기화가 꺼져 있거나 읽기 전용인 캘린더는 제외합니다.
6. 가져오는 일정의 공개 범위를 선택합니다. 기본은 **나에게만 보이기**이며 **모두에게 보이기**로 바꿀 수 있습니다.
7. Famical에서 새로 만든 개인 일정도 내보내려면 **새 개인 일정도 휴대전화로 내보내기**를 선택합니다. 기본은 OFF입니다. 내보낸 일정은 선택한 외부 캘린더의 공유 권한을 따릅니다. 이미 연결된 일정은 공개 범위를 바꿔도 연결을 유지합니다.
8. 안내를 확인하고 **양방향 연동 시작**을 누릅니다.

삼성 계정 비밀번호를 Famical에 입력하지 않습니다. Android Calendar Provider에 공개된 기기 내 일정만 접근합니다. 삼성의 특정 캘린더가 목록에 나타나지 않으면 해당 계정 데이터를 이 방식으로 읽고 쓸 수 없는 상태입니다. 삼성 클라우드 전체 내역을 NAS가 직접 다운로드하는 기능은 아닙니다.

## 반영 범위

| 항목 | 동작 |
| --- | --- |
| 일반 양력 일정 | 선택한 캘린더 ↔ 본인 Famical 일정의 추가·제목·메모·시작일·종료일·시작 시간·삭제 반영 |
| 삼성의 반복 일정 | 지난달 1일부터 앞으로 약 12개월까지 발생 날짜별로 가져오기. Famical에서는 조회만 가능하며 원본 삼성 캘린더에서 수정·삭제 |
| Famical 음력·매년 반복 | 해당 범위의 양력 날짜로 변환해 휴대전화에 **보기 · 제목**으로 표시. 반복 규칙은 Famical에서 수정 |
| 다른 가족이 작성한 공유 일정 | Famical·위젯에서는 계속 표시. 본인의 휴대전화 캘린더에 다시 복사하지 않음 |
| 공개 범위·막대 색상 | Famical에서 관리. 기기 캘린더의 공개 범위·계정 공유 권한을 바꾸지 않음 |
| 알림·참석자·장소 | Famical로 가져오지 않음. 기존 휴대전화 일정 수정 시 이 필드들은 유지. 새로 내보낸 일정에는 알림·참석자를 생성하지 않음 |

범위는 지난달 1일~현재 월에서 12개월 뒤의 직전 월말입니다. 새로 가져오거나 내보낼 일정에 적용하며, 이미 연결된 일반 일정은 이 범위를 벗어나도 연결을 유지합니다. 범위를 벗어난 반복 발생일이 조회되지 않는 것을 삭제로 취급하지 않습니다.

기기 원본의 종료 시간은 제목·메모만 수정할 때 그대로 유지합니다. 웹 화면에는 종료 시간 입력란이 없어, 날짜·시작 시간을 바꾼 경우 원래 종료 시각을 가능한 한 유지합니다. 새 시간 일정의 기본 길이는 1시간이며, 종일 일정은 종료일까지 포함합니다. 366일 초과 기간·100자 초과 제목·2,000자 초과 메모는 가져오지 않고 지원 범위 초과 건수로 알립니다.

음력 원본 규칙·삼성 전용 생일 설정·알림 등의 모든 전용 메타데이터를 변환하는 기능은 아닙니다. 반복 원본의 규칙을 양쪽에서 직접 편집하는 완전한 반복 일정 동기화는 지원하지 않습니다.

## 갱신·충돌·연결 해제

- 자동 동기화 요청은 **1시간**이며 앱을 다시 열 때도 시도합니다. Android 절전·백그라운드 제한·네트워크 상태에 따라 지연됩니다. 위젯의 표시 갱신과 캘린더 데이터 동기화는 별개의 작업입니다.
- 앱의 연동 메뉴에서 **지금 동기화**로 수동 실행하고 마지막 결과·반영·충돌·지원 범위 초과 건수를 확인할 수 있습니다.
- 양쪽에서 동시에 수정한 일정, 한쪽 삭제 중 다른 쪽 수정은 자동 덮어쓰기하지 않고 보류합니다. 연동 메뉴의 **휴대전화 우선** 또는 **가족 달력 우선**은 해당 충돌에 한 번 적용됩니다. 가족 달력에서 삭제된 일정을 휴대전화 우선으로 복구하면 공개 범위는 나에게만으로 복구합니다.
- 반복·음력 보기용 복사본을 휴대전화에서 편집해도 원래 반복 규칙을 바꾸지 않습니다. 원본 앱에서 수정하세요. 변경된 보기용 복사본은 충돌로 보류됩니다.
- 캘린더가 없어지거나 조회·권한 확인에 실패하면 삭제 반영을 중단합니다. 휴대전화 일반 일정이 한 번에 6개 이상 사라진 경우에도 자동 삭제를 보류합니다. 의도한 삭제인지 확인한 뒤 휴대전화 우선으로 실행할 수 있습니다.
- 중복 방지 연결 정보와 삭제 기록을 NAS에 저장합니다. 통신 실패 후 재시도해도 삭제한 일정을 자동으로 되살리지 않습니다.
- **연동 해제**는 자동 연동과 NAS 연결을 끊고 양쪽 일정을 그대로 둡니다. NAS 연결이 실패하면 기기 자동 연동부터 멈추고 연결 해제를 다시 시도하도록 알립니다.
- 한 Famical 계정은 한 휴대전화·한 캘린더를 연결합니다. 다른 기기·캘린더로 바꾸기 전 기존 연결을 해제하세요. 서버 주소 변경 시 기기 자동 연동을 중지하며, 다른 가족 계정으로 로그인하면 이전 계정의 연동을 실행하지 않습니다.
- 같은 외부 캘린더를 여러 Famical 계정에서 각각 가져오면 작성자별 일정이 따로 만들어집니다. 가족 모두에게 같은 외부 일정을 공유하려면 한 계정에서 가져와 모두에게 보이기로 연결하세요.

## 기기에서 확인할 순서

자동 테스트에서는 Android 캘린더 제공자를 모의하여 양방향 추가·수정·삭제, 충돌 보류·복구, 중복 복구, 계정 분리, 종일 기간과 반복 조회 범위를 검증했습니다. 실제 삼성 휴대전화·삼성 클라우드와의 동기화는 이 빌드 환경에서 검증하지 못했습니다.

먼저 선택한 캘린더에 테스트 일정 하나를 만들고 Famical에서 보이는지 확인하세요. 이어 Famical에서 본인 일반 일정 하나를 만들고 삼성 캘린더에 나타나는지, 양쪽 수정·삭제가 반영되는지 수동 동기화로 확인한 뒤 사용하세요. iPhone에서는 NAS를 통해 공유된 일정을 볼 수 있으며, 이 기능이 iPhone 기본 캘린더와 직접 연동하는 것은 아닙니다.
