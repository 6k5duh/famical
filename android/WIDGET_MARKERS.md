# Android widget v1.1.2

- 일정이 있는 날짜 아래에 일정 색상에 맞는 막대를 표시합니다.
- 오늘뿐 아니라 이번 달 전체 일정에 표시하며, 기간 일정은 시작일부터 종료일까지 포함합니다.
- 같은 날짜에 여러 일정이 있으면 최대 3개의 색상 막대로 표시합니다.
- 오늘 날짜는 **빨간색 테두리**로 구분합니다. 주·야간 배경색은 유지합니다.
- 자동 갱신 요청 주기는 **1시간**입니다. 기기 절전 정책에 따라 실제 실행은 지연될 수 있습니다.
- 갱신 버튼과 로그인·표시 설정 변경 후 갱신은 계속 사용할 수 있습니다.
- 개인 일정은 기존 ‘위젯에 나의 개인 일정 표시’ 설정을 따릅니다. 기본적으로 개인 일정 막대도 숨깁니다.

## 적용

1. 기존 앱에 APK를 업데이트 설치합니다. 같은 인증서로 서명했으므로 앞서 제공한 APK 위에 설치할 수 있습니다.
2. 앱을 한 번 열고 홈 화면으로 돌아와 위젯의 갱신을 누릅니다.
3. 하단에 `v1.1.2`가 표시되는지 확인합니다.
4. 이전 배치가 남아 있으면 위젯만 제거 후 다시 추가합니다.

[테스트 화면](../downloads/widget-preview-1.1.2.png)

자동 테스트 14개로 월 전체 캐시, 기간 경계, 개인 일정 숨김, 빨간 테두리의 실제 픽셀, 1시간 주기 리소스와 세 가지 크기의 렌더링을 확인했습니다. 실제 휴대전화 런처와 절전 정책에 따른 갱신은 기기에서 확인해야 합니다.
