# 달력 for Android v2.2.3

[최신 APK 다운로드](../downloads/famical-android-2.2.3.apk)

1. NAS 소스를 v2.0.1으로 업데이트하고 Container Manager에서 다시 빌드합니다. 기존 계정·일정 데이터 볼륨과 설정 파일은 유지합니다.
2. APK를 내려받아 기존 앱 위에 업데이트 설치합니다. Android 8.0 이상이 필요합니다.
3. 기본 서버 `https://famical.ymsh.synology.me/`의 가족 계정으로 로그인하고 첫 동기화를 마칩니다.
4. 이후 인터넷·NAS가 끊겨도 앱을 열고 일정을 확인·추가·수정·삭제할 수 있습니다.

v2.0.1은 기본 Android UI와 Canvas로 달력을 그리며 SQLite에 일정·미전송 변경을 함께 저장합니다. 브라우저의 웹앱도 같은 서버에서 계속 사용할 수 있습니다.

일정 색상은 배경색과 구분되는 16가지이며 선택창에 색상 견본을 표시합니다.

## 스와이프로 달력 보기

달력에서 왼쪽으로 밀면 다음 달, 오른쪽으로 밀면 이전 달로 이동합니다. 월 이동에는 약 0.24초의 슬라이드 효과, 접기·펼치기에는 약 0.26초의 높이 전환 효과를 적용합니다. 기기 설정에서 애니메이션을 끄면 즉시 전환합니다. 위로 밀면 달력이 줄어들고 아래에 선택한 날짜의 일정 목록을 표시합니다. 처음 선택한 날짜는 오늘이며, 다른 달로 이동할 때는 같은 일자를 선택합니다.

하단 목록은 한 화면에 일정 3줄을 표시합니다. 일정이 더 많으면 목록 안에서 위아래로 스크롤하세요. 날짜를 누르면 목록이 해당 날짜로 바뀌고, 목록의 일정을 누르면 상세 내용을 열 수 있습니다. 하단 **+**는 선택한 날짜에 새 일정을 추가합니다.

달력을 아래로 밀거나 하단 **펼치기**를 누르면 전체 달력으로 돌아갑니다. 상단 월 제목을 눌러도 목록을 열거나 닫을 수 있습니다.

## 일정과 동기화

날짜를 누르면 일정 목록과 추가 항목을 표시합니다. 제목, 시작일·종료일, 시간, 음력·양력·윤달·연간 반복, 가족·회사 구분, 공개 범위, 색상, 메모를 설정할 수 있습니다. 숫자 8자리 날짜는 YYYY-MM-DD로 변환됩니다. Android 새 일정의 공개 범위는 모두에게 보이기입니다.

저장은 기기에 즉시 반영하며 연결 중에는 서버에 전송합니다. 앱이 보이는 동안에는 1분마다 동기화를 시도하고, 다시 앱을 열 때도 시도합니다. 상태 줄을 누르면 수동 동기화합니다. 재시작 후에도 미전송 변경을 보관합니다. 앱이 닫힌 상태에는 네트워크 연결을 기다리는 작업과 1시간 주기의 Android 백그라운드 작업으로 동기화를 시도합니다. 절전·백그라운드 제한에 따라 지연될 수 있습니다.

같은 일정을 여러 기기에서 수정했다면 설정에 내 일정과 서버 일정을 표시합니다. **내 변경 적용** 또는 **서버 일정 사용**으로 해결합니다. 서버에서 삭제된 일정에 내 변경을 적용하면 새 일정으로 등록합니다. 잘못된 입력·권한 오류는 설정에서 확인하거나 변경을 취소할 수 있습니다.

세션이 만료되면 설정의 **같은 계정으로 재로그인**으로 동기화를 재개합니다. 미전송 변경이 있으면 동기화·충돌 확인 후 로그아웃하거나 서버를 바꿉니다. 앱을 삭제하거나 Android 설정에서 앱 데이터를 지우면 기기에만 있던 미전송 변경도 삭제됩니다.

설정에서 일정 구분·내 일정 필터, 교대조와 서버를 설정합니다. 회사 연속 일정은 토·일을 제외한 경과 일수·총일수를 표시합니다. 이전 달·다음 달 날짜는 흐리게 표시합니다. 음력은 1900~2050년, 공휴일 데이터는 1900~2099년이며 2027년 회사 휴무를 포함합니다. 공휴일 제도 변경은 앱 데이터 업데이트로 반영합니다.

가족 계정 생성과 비밀번호 변경은 같은 서버의 웹앱에서 이용할 수 있습니다.

## 위젯과 휴대전화 캘린더

홈 화면을 길게 누르고 위젯 → 우리 가족 달력을 추가합니다. 오늘 빨간 테두리, 일정 막대, 크기별 레이아웃과 1시간 갱신 요청을 지원합니다. 네이티브 로그인 이후에는 기기 저장 일정에서 위젯을 표시하며, 갱신 때 데이터 동기화도 시도합니다. OS 절전 정책에 따라 갱신이 늦어질 수 있습니다.

위젯의 개인 일정 표시는 기본적으로 꺼져 있으며 앱 설정에서 변경합니다. 삼성·휴대전화 캘린더 양방향 연동은 기존 설정을 유지하며 앱 설정에서 관리합니다. [연동 안내](CALENDAR_SYNC.md)

## 빌드

JDK 17 이상과 Android SDK 35를 준비하고 `cd android`, `./gradlew assembleRelease`를 실행합니다. R8 코드 축소와 리소스 축소를 적용합니다. 현재 배포 APK는 기존 APK와 업데이트 호환성을 위해 같은 개발용 인증서를 사용하며, 릴리스 빌드로 디버깅을 비활성화합니다. 재현 빌드에는 같은 서명 키가 필요합니다.

음력·공휴일 데이터는 `native/assets/calendar.dat`에 압축해 포함합니다. Python 의존성 설치 후 `python native/build_calendar.py`로 재생성합니다.

Android v2.1.2에서는 홈 화면 위젯의 날짜 칸을 누르면 해당 월·날짜를 선택하고 하단에 그날의 일정 목록을 엽니다. 이미 앱이 실행 중이어도 적용됩니다. APK 업데이트 후 위젯의 갱신 버튼을 한 번 누르세요. NAS가 v2.0.1이면 서버 재설치는 필요 없습니다.

## 휴가 요청 SMS 자동 등록 (v2.2.0)

1. 앱 업데이트 후 로그인하고 **설정 → 문자 자동 등록 켜기 → 켜기**를 누릅니다.
2. Android의 SMS 수신 권한을 허용합니다. 기능은 기본적으로 꺼져 있습니다.
3. 이후 `052-219-5000`에서 오는 `[Web발신]`과 `[휴가승인 요청]`이 포함된 SMS에서 신청자·시작일·종료일·휴가 종류를 읽어 자동 등록합니다. 헤더의 공백과 발신번호의 하이픈, `+82` 형식을 허용합니다.

예시의 신청자 `강지은`, `연차/월간연차`는 **강지은 년차**로 등록됩니다. **양력·종일·회사·나에게만 공개**이며 반복하지 않습니다. 여러 날이면 시작일·종료일을 저장하고 기존 회사 연속 일정과 같이 토·일에는 표시하지 않습니다. 11/20~11/24는 금요일 (1/3), 월요일 (2/3), 화요일 (3/3)로 표시합니다. 단일 날짜는 그 날짜에 표시합니다.

승인 요청이 오면 즉시 등록하며 별도의 승인 완료 확인은 없습니다. 일정 메모에는 요청 문자에서 자동 등록했음을 표시합니다. 취소 문자는 오지 않으므로 휴가가 취소되면 직접 수정·삭제하세요. 같은 신청자·기간·휴가 종류의 재수신은 중복 등록하지 않습니다. 자동 등록 일정을 삭제한 뒤 같은 문자를 재수신해도 다시 만들지 않습니다.

서버 연결이 없어도 기기에 저장하고 연결되면 동기화합니다. 문자 원문은 저장·업로드하지 않고 생성한 일정과 중복 방지 해시를 보관합니다. 권한 허용은 해당 번호의 발신자 신원을 보증하지 않으며 문자에서 읽은 내용대로 등록합니다.

설정에서 최근 자동 등록 시각을 확인하거나 기능을 끌 수 있습니다. 로그아웃하면 자동 등록도 해제됩니다. 이전 수신함은 읽지 않고 켠 이후의 SMS와 분할 SMS만 처리합니다. MMS/LMS/RCS는 처리하지 않습니다. 앱을 강제 중지했거나 SMS 권한이 취소되면 재실행·권한 허용이 필요합니다. 일부 기기·APK 설치 프로그램은 SMS 권한을 제한할 수 있습니다. 실제 휴대전화 수신은 아직 검증하지 않았습니다. Google Play 배포 시에는 별도의 SMS 권한 정책 심사가 필요합니다.

## 휴가 종류 약칭 (v2.2.1)

새로 수신하는 휴가 요청은 `신청자 약칭`으로 등록합니다.

| 문자 휴가 종류 | 일정 약칭 |
| --- | --- |
| 연차/월간연차 | 년차 |
| 생리휴가 | 생휴 |
| 경조휴가 | 경조 |
| 향군(예비군) | 향군 |
| 유급(근속휴가, 대체휴가등) | 유급 |
| 무급 | 무급 |
| 산전후휴가 | 출산 |
| 가족돌봄휴가 | 돌봄 |
| 유계결근(연차/월간연차 잔여 부족) | 유결 |

괄호 설명이 없는 명칭도 인식합니다. 예를 들어 `강지은 생휴`, `강지은 출산`으로 등록됩니다. 기존 등록 일정 제목은 자동 변경하지 않으며, 이전 버전에서 긴 명칭으로 자동 등록된 휴가도 재수신 시 중복 생성하지 않도록 처리합니다. 회사·개인 공개·연속 기간의 주말 제외 설정은 그대로 적용됩니다.

Android v2.2.2에서는 달력 하단의 동기화 날짜·시간을 숨기고 정상 완료 시 상태 줄을 접습니다. 미전송·오류와 로그인 안내는 유지하며 실제 동기화 주기는 변경하지 않았습니다.

Android v2.2.3에서는 위젯 하단의 버전·기기 저장 일정 등 상태 문구를 숨기고 날짜 제목을 4sp 확대했습니다(일반 폭 21sp, 넓은 위젯 26sp). 좁은 위젯에서는 두 줄까지 표시합니다. 갱신 버튼·시간당 갱신 요청·날짜 터치 이동은 유지합니다. 기존 앱 위에 업데이트한 뒤 위젯의 갱신 버튼을 눌러 주세요. NAS 재빌드는 필요 없습니다.
