# Android widget layout fix — v1.1.1

[위젯 수정 APK 다운로드](https://github.com/6k5duh/famical/raw/refs/heads/main/downloads/famical-android-1.1.1-debug.apk)

## 바뀐 내용

- 고정 크기 텍스트 달력을 7열의 날짜별 실제 칸으로 교체했습니다.
- 달력이 남은 위젯 영역을 채우고 날짜 글자는 칸 크기에 맞춰 자동 조절됩니다.
- 4·5·6주 달력을 구분해 사용하지 않는 주를 숨깁니다.
- 위젯 크기 변경 및 폴더블의 화면 크기 변화를 반영합니다.
- 작은 크기에서는 일정 요약 줄 수를 줄이고, 공간이 매우 작은 경우 달력을 우선 표시합니다.
- 기존 위젯을 갱신할 때 새 레이아웃을 다시 불러오도록 레이아웃 ID를 구분했습니다.
- 하단에 앱 버전 `v1.1.1`을 표시합니다.

## 적용

1. APK를 내려받아 기존 앱에 **업데이트 설치**합니다. 앞서 제공한 v1.0.0/v1.1.0과 같은 서명입니다.
2. 앱을 한 번 열고 홈 화면으로 돌아옵니다.
3. 위젯의 **갱신** 버튼을 누릅니다. 필요하면 크기 조절 핸들을 한 번 움직여 새 배치를 적용합니다.
4. 이전 배치가 남아 있다면 홈 화면의 **위젯만 제거한 뒤** 위젯 → 우리 가족 달력을 다시 추가합니다. 앱이나 계정을 지우는 과정은 필요하지 않습니다.

## 검증

Android SDK 기반 Robolectric 네이티브 렌더링으로 260×280, 300×480, 480×400 크기의 화면을 생성해 확인했습니다. 날짜 칸 너비·높이 확대, 빈 주 숨김, 날짜 범위와 갱신 버튼 위치를 테스트했습니다. 자동 테스트 10개, APK 빌드, lint 및 서명 검증이 통과했습니다. 실제 삼성 런처 동작은 기기에서 업데이트 후 확인해야 합니다.
